## 下载与升级

Windows x64 下载 `WorkBuddy-theme-workbench_1.6.4_candidate_x64-setup.exe`。先保存编辑并退出旧主题切换器，再运行安装包；已有主题、草稿和设置保留，建议事先备份 `%LOCALAPPDATA%\WorkBuddyThemeSwitcher`。安装包自带 Node 与 CodeDrobe，无需开发工具。

这是 **1.6.4 预发布候选版**，不替换正式最新版。已连接 WorkBuddy 时无需重启；需要开启连接时仍由用户单独确认。

## 修复内容

- 新版首页、会话外壳的白底遮挡，以及正文、输入框、发送按钮、表格、代码、菜单和弹窗的兼容映射。
- 成品主题与图片主题分别使用自己的颜色；原成品包、图片与已保存修订不改写。
- 结构识别、场景必要检查和实际样式校验共用一套契约，未知结构或缺失检查不再误报通过。
- 后台窗口的本地图片解码、恢复命令参数及失败错误码；失败回退、试用与截图采用同一生效样式身份。
- 设置页新增场景覆盖与脱敏诊断导出，不包含聊天、账户、截图或 CSS 正文。

继续保持纯离线、三套图片风格、默认零模糊、自动寻找路径、10 分钟可回退试用和恢复原版，不改变控件布局或滚动结构。
