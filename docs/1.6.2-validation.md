# 1.6.2 图片自适应融合：候选版验证说明

日期：2026-09-16。基于 1.6.1；本轮没有关闭旧切换器、操作 WorkBuddy、读取聊天、实机截图或覆盖安装。

## 实现

- 风格 ID 不变，新增风格 v2 / ImageAnalysis v2。新导入、切换新版风格和恢复新版默认值均为 0px 模糊；不接入 AI、不修改导入源文件。
- 导入时一次解码并缓存 16×16 颜色网格、亮度分布/标准差/相邻差异和饱和度。普通微调仅提交完整参数和序号，不解码原图、不重新推荐风格。
- `theme_fusion.rs` 为固定版本的纯编译模块；v1 编译及默认值单独保留。新版共享模板明确“外层底色与内描边、已知内层透明”，不修改消息/列表尺寸、位置、滚动、点击与显示条件。
- 主画布由内容区外层统一负责，顶栏与聊天区透明继承；侧栏使用衍生底色并覆盖选中/悬停/底部；助手消息 18px 圆角；输入框真实 `_mainArea_`、编辑区和工具栏透明，只保留一个视觉框。
- 实际 `_icon_` + `_large_` 发送控件、Markdown、链接、代码、表格、引用、菜单和弹窗均有局部样式。原有主题装饰和固定冰蓝色没有复制到新模板。
- 面板滑块表示相对当前风格默认值的百分点；基础层次采用计划中的 28/40/34 等不透明度。可读性按图片→画布→消息/输入框计算；正文/辅助文字 4.5:1，聚焦提示 3:1。装饰边框不强制变黑。
- 浏览器独立叠色检查发现“重复消息底色”会降低引用链接可读性，已为表格/代码/引用建立经校验的细节底色。无法覆盖的裁切、未采样纹理及动态状态明确标为未验证。
- “创建新版融合副本”使用独立草稿 ID；保留图片、名称、背景位置及手动强调色，重建区域参数并归零模糊，不保存正式主题或应用。支持后台取消、超时、发布失败回退。

## 兼容与未完成验收

- 适配结构以本机 WorkBuddy 5.2.6 为基准；**本轮实机未验收**。不承诺所有 5.3.x 版本兼容。
- 已保存主题仍直接使用原 CSS。v1 草稿普通编辑使用冻结的 v1 路径，升级 v2 必须创建副本。此前 1.6.1 对 v3.1 草稿的背景兼容修复仍保留，不重写其正式修订。
- 不依赖旧 AI Key；保留已有独立、需确认的历史凭据清除入口。
- 试用、自动保持、实机抓图及回退通道不重写。本轮只运行其已有隔离回归，不能当作新的实机 10 分钟超时、断连恢复、保留应用或重启验收。
- 待用户另行允许后：在空白首页使用隔离数据执行换肤/截图/回退，并由用户手动打开脱敏聊天、菜单、弹窗；检查 1/0 节点、输入滚动点击、原主题恢复。实机同步/截图耗时需单独测量。
- 此包标为“候选版／实机待验收”，尚未覆盖安装。安装不是本轮自动操作。

## 复现命令

在项目目录、已安装 Node/Rust/Windows 构建依赖的环境运行：

```powershell
npm run typecheck
npm run lint
npm test
$env:STUDIO_QA_FIXTURES = "$PWD/.qa/engine-fixtures.json"
node scripts/run-with-cargo.mjs cargo test --manifest-path src-tauri/Cargo.toml --offline -- --nocapture
npm run test:e2e
$env:CARGO_NET_OFFLINE = 'true'
npm run package:installer
```

浏览器测试需本机 Edge；代理环境须放行 localhost/127.0.0.1。首次配置开发依赖可能需要联网，与软件业务完全离线是不同事项。
