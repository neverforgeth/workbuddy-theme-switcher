## 下载

Windows 64 位请下载 `WorkBuddy-theme-workbench_1.6.3_candidate_x64-setup.exe`。退出旧版主题切换器后运行安装包，再打开切换器选择主题并应用。无需安装 Node、运行命令或手动复制文件。已经连接 WorkBuddy 时无需重启；需要开启连接时，由使用者保存工作并在界面确认。

## 本次修复

- 四个内置主题支持新版 `.cr-input-container` 输入框，兼容原有输入框结构；补齐输入区、工具栏、发送按钮、聚焦与禁用外观。
- 修复空白或已关闭的附属窗口拖住主窗口主题预检查/验证的问题。
- 修复具体错误被吞成 `EXIT1` 的问题：显示可定位的错误码与检查项，日志不记录页面内容。
- 自动保持遇到确定性错误暂停重试，保留实际原因，不再反复显示泛化错误。
- 安装包携带完整本地运行资源；已在中文及空格路径中复核包内文件与换肤应用/恢复链路。

保留图片编辑、默认零模糊、内置主题、自动寻找路径、真实预览与恢复原版。旧自定义主题和不可变修订不自动改写。

本包沿用候选版标识。测试范围和现场验收边界见 [验证说明](https://github.com/neverforgeth/workbuddy-theme-switcher/blob/v1.6.3/docs/1.6.3-validation.md)。
