## 实现

- `workbuddy-compat/dom.js` 是 Rust、CodeDrobe 与截图共同使用的只读结构契约。通用 `#root`、未知会话和缺少必要输入组件不能通过。
- `builtin.css` 只读取原成品主题变量；`image.css` 只读取图片融合主题分区变量。`components.css` 负责 CR 会话与输入框的绘制映射，不改几何、滚动或点击区域。旧版结构不追加 CSS。
- `EffectiveTheme` 包含原 CSS 哈希、适配版本、结构、最终 CSS 与哈希。运行时包放在应用数据目录的 `effective-themes`，缓存键包含完整源包（包括图片）与最终样式身份。
- 旧修订、原成品主题与资源不写回。`tests/builtin-1.6.3-sha256.json` 冻结了提交 `5464aa230428bba3a3e22ab5603d74fec805a43c` 的资源哈希。
- 试用记录保存最终 CSS、最终哈希、原效果身份与 CSS，并固定 CDP 目标。实时微调不写入正式主题；截图、确认与回退使用相同最终样式。
- 普通应用先记录可识别的原效果。失败时恢复它，而不是无条件清除主题；断连或未知外部样式保留恢复记录。`apply-recovery.json` 在下次可连接时优先恢复。
- `CompatibilityReport` 区分身份、必要结构、实际背景／文字检查及未检查状态。已知样式覆盖失败停止自动重试；可识别的旧原始 CSS 允许升级到运行时补丁。
- 诊断导出到日志目录，只含软件版本、适配版本、场景、静态检查名／错误码和耗时；不导出聊天、输入、CSS、截图、账户及安装路径。
