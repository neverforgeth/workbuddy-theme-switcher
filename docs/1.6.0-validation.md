## 性能及测量边界

- 同一导入草稿连续 60 次编辑，包含缓存编译、文档读取/验证及草稿原子写入；最新一轮 Debug P95 **48.87ms**。此前完整测试并发轮次为 64.21ms、78.93ms。
- 此数字**不含前端 100ms 合并提交延迟、Tauri IPC、WorkBuddy CSS 同步、窗口绘制及截图**。完整“滑块到画面”P95 ≤200ms 尚未实机测量，不能据此宣称已经达标。
- 测试在临时数据目录故意损坏受控图片后继续微调，验证更新不再解码图片；正式用户数据未改动。
- 截图前端至少间隔 1100ms、后端至少 1 秒；仅参数更新或主动刷新触发。状态探测沿用约 2.5 秒一次、前端事件＋10 秒补充轮询。
- 实机同步耗时、截图耗时、生成时间和滚动流畅度尚需授权后的独立测量。

- 适配选择器和仿真结构针对 WorkBuddy 5.2.6。1.6.0 尚未重新完成本机应用/重启保持实测；不把历史版本测试结果归为本版验证，不承诺全部 5.3.x。
- 旧 schema 1/2 与旧主题包保持可读/可应用；存储仍使用已有 ID 与修订寻址。旧 CSS 在打开和保存旧修订时保持不变。
- 新 CSS 不添加控件尺寸、滚动规则、布局位移或显示条件；仅背景伪元素含装饰定位。按钮 disabled 不可读性减淡被替换为明确颜色，功能禁用仍由 WorkBuddy 控制。
- 对比度是样本与面板叠加检查，正文目标 4.5:1，关键输入/主按钮边界与聚焦目标 3:1。修正值和原因随编译结果返回，动态状态标为未验证。
- 旧凭据清理为精确 `CredDeleteW`，必须确认；不存在时视为已清理。拒绝确认的测试不调用 Windows 删除。真实凭据未被读取或清除。
- 浏览器回归阻止并检查非本地请求；没有执行系统级断网操作，也没有完成真实 Tauri 运行时的离线抓包验收。
- 主窗口 CSP 已编译进候选包；实际 WebView 的本地图片、IPC 与 CSP 需实机启动后复核。辅助 iframe 的 CSP/脚本隔离已做浏览器验证。
